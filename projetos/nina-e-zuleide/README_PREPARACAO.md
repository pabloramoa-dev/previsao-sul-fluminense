# Nina e Zuleide — projeto independente (pacote para importar)

Esta branch é uma área de **preparação** e não altera a produção atual de Previsão do Tempo, Nina Me Contou nem outros workflows.

A conexão atual do GitHub permite criar branches e arquivos dentro de repositórios existentes, **mas não criar um repositório novo**. Por isso o pacote completo está preparado como ZIP nesta conversa, para importação futura em um repositório exclusivo `pabloramoa-dev/nina-e-zuleide`. O projeto não deve ser mesclado à branch `main` do Sul Fluminense.

## Entregáveis preparados

- 50 episódios ficcionais individuais com ganchos no primeiro diálogo, revelação e conclusão; sem parte 2.
- Nina: adulta, paqueradora atrevida; namoros e pretendentes atrapalhados do prédio, sem conteúdo explícito.
- Zuleide: amiga confidente fofoqueira que investiga e reage aos romances.
- Layout vertical 9:16, retratos dos personagens originais em close 3x4, SEM Kugutu.
- Dois conjuntos de imagens de apoio SEMPRE DIFERENTES: 10 cenas x 2 imagens (Nina e Zuleide) por episódio.
- Prompts criados a partir do roteiro ANTES da chamada SiliconFlow e verificações de arquivos distintos.
- Workflow manual por episódio; `mock` para teste gratuito e `paid` para SiliconFlow, mediante secret `SILICONFLOW_API_KEY`.
- MP4 H.264/AAC, sem autopublicação.

O pacote ZIP contém a pasta `.github/workflows`, `scripts`, `episodes/001.json` até `episodes/050.json`, testes e documentação com referências de tendências.

**Testes locais:** catálogo 50/50 validado; composição demonstrada com H.264/AAC, duração completa e dois streams de imagens distintos. **Integração GitHub final não validada na nova conta, porque o repositório novo e o Secret ainda precisam ser criados.**

## Pesquisa

Padrões narrativos vieram de exemplos documentados de reels/TikTok: áudio enviado por engano, entregas trocadas, encontros inesperados e fotos fora de contexto; não são cópias dos criadores nem 50 virais certificados. Relatórios TikTok Next e Metricool corroboram interesse em micro-histórias, humor e formatos compartilháveis.

Depois de criar o repositório vazio novo, o pacote pode ser enviado integralmente. Esta branch guarda o planejamento e a lista editorial.
